Compatibility, limitations & interactive checks

This alpha uses regular SVG source filters. It does not use SVG backdrop-filter, a DOM mirror, or html2canvas. Refraction checks pass in Chromium, Firefox, WebKit, and native macOS Safari 26.6.2. iOS device and performance testing are still pending. This SVG playground uses DOM sources; the component library demonstrates the separate media renderer. Transformed sources remain outside this contract. Map preparation includes PNG encoding and decoding; it is not GPU time.
