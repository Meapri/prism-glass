Compatibility, limitations & interactive checks

This alpha uses regular SVG source filters. It does not use SVG backdrop-filter, a DOM mirror, or html2canvas. Native Safari and Firefox visual verification is still required. Video/canvas sources and transformed sources are outside this release's contract. Map preparation includes PNG encoding and decoding; it is not GPU time.
